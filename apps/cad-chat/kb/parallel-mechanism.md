# 平行機構:史都華平台(六足)、多腿並聯

## 適用情境

動平台由多支可伸縮的腿同時支撐與驅動(史都華平台/六足平台、三腿調平台、運動模擬座)。特徵是
「平台的姿態決定每支腿的長度」,不是一軸疊一軸。一軸疊一軸的串聯機構看 `layout-selection.md`。

## 計算與選型

**1. 逆運動學(由姿態求腿長)**——平行機構的設計都從這條開始:
- 基座接頭座標 b_i(固定)、平台接頭在平台座標系的位置 p_i、平台姿態 = 平移 c + 旋轉 R。
- 第 i 支腿長 L_i = | c + R·p_i − b_i |。六支腿各算各的,彼此獨立,是閉式解。
- 反過來「由腿長求姿態」(正運動學)沒有閉式解,要迭代——設計與建模都用逆運動學,不要走正向。

**2. 接頭佈局(6-6 型)**
- 基座接頭三對,分布在 0° / 120° / 240° 附近;平台接頭三對,分布在 60° / 180° / 300° 附近
  (與基座錯開 60°)。每對兩個接頭夾角的一半常取 10–20°。
- 基座與平台的接頭六邊形**不可相似**(同形狀只差比例會落在奇異構型,平台在某個方向失去剛性)。
  平台接頭圓半徑取基座的 0.5–0.8 倍是常見比例。
- 腿的仰角(腿與水平面夾角)設計在 55–75°:太平 → 垂直承載差、腿受力大;太直 → 水平方向剛性差。

**3. 行程與工作範圍**
- 致動器(電動缸)的最短長度 ≈ 行程 + 固定的機構長度,所以最長 / 最短長度比通常不超過 1.5–1.7。
  先由工作範圍的各個極端姿態用逆運動學算出所需的 L_min、L_max,再回頭選致動器。
- 每個極端姿態還要驗接頭擺角:球接頭容許擺角約 ±15–25°,十字(萬向)接頭可到 ±40°。平移與傾斜
  同時達到極值的角落姿態最容易超限。
- 腿與腿、腿與平台/基座在極端姿態下的淨空也要驗——同一對的兩支腿在平台側靠得最近。

**4. 受力**
- 純垂直負載 W、姿態對稱時,每支腿的軸向力 ≈ W /(6·sin φ),φ = 腿的仰角。偏心負載或傾斜姿態下
  各腿受力不均,最大的一支可達平均的 2 倍以上——選致動器推力留 2–3 倍餘裕。
- 每支腿只受軸向力(兩端是球接頭/萬向接頭),這是平行機構剛性高的原因;致動器本身不能承受側向力。

**5. 接頭型式**
- 兩端都用球接頭:腿多一個繞自身軸線的空轉自由度,不影響平台,但線纜會跟著轉。
- 一端萬向接頭、一端球接頭(UPS 型):消除空轉,最常見。
- 接頭中心必須準確落在 b_i、p_i 上——接頭中心偏了,逆運動學算出來的腿長就不對。

## 在本系統怎麼做

- 參考模型 `models/stewart_platform/stewart_platform.py`,先讀再改(換接頭半徑、高度、致動器尺寸、
  姿態範圍)。它的寫法:
  - **姿態是輸入**:六個姿態量(dx, dy, z0, roll, pitch, yaw)放 PARAMS,由**同一個** Location
    (`_pose()`)同時定平台實體與六個平台接頭位置——兩者不可能對不上。滑桿改姿態就是重新做一次
    逆運動學。
  - **腿沿局部 +Z 建好,再用「以基座接頭為原點、腿方向為 Z」的平面定位**;筒與桿各自定位
    (筒長固定、桿的位置由當下腿長決定)。
  - `_check_params` 把機構極限變成人話:每支腿在起點與行程終點的長度落在致動器範圍內、仰角落在
    接頭擺角範圍內。滑桿調到做不到的姿態時,使用者看到的是「第幾支腿需要多長、超出範圍」。
- **運動宣告只能表達一條軌跡**(一個主動進度帶動全部從動)。參考模型選的是「由目前姿態沿 Z 升降」:
  升降時每支腿都留在通過它基座接頭的鉛直面內,所以每腿兩個從動 dof 就精確——桿沿基準腿軸伸長
  (先宣告)、整支腿繞基座接頭的水平軸擺(後宣告);兩者都帶 profile(逆運動學在升程上等分取樣)。
  合計 1 + 6×2 = 13 個 dof(上限 16)。
- 一般的六自由度軌跡(平台同時平移加傾斜)每腿要三個從動 dof、平台自己也要平移加旋轉,超過上限
  ——不要硬做:挑一條有代表性的軌跡做運動示意,其餘姿態自由度交給滑桿,並在回覆講明。
- 配對要列每支腿的:桿×筒(伸縮)、筒×基座(球在球窩)、桿×平台(球在球窩)。球與球窩留徑向
  間隙(參考模型 0.3 mm)、桿與筒內孔留間隙,都不列入預期接觸。
- 沒有電動缸的標準件家族:腿用簡化的筒+桿;要真外形請使用者提供原廠 STEP。

## 做不到與要講明的事

- 不解正運動學、不算奇異點、不算工作空間邊界、不算剛性。只驗你給定的那個姿態與那條軌跡上的幾何
  (腿長範圍由 `_check_params` 擋、干涉由掃掠查)。
- 運動示意只有一條軌跡;「平台可以六個方向動」是靠滑桿逐一調姿態看,不是連續播放。
- 受力是對稱姿態的估算。實際各腿受力要對每個姿態解靜力平衡,本系統不做。
- 接頭擺角極限、致動器長度比都是典型值,以實際選用的接頭與電動缸型錄為準。

## 來源與信心

- 逆運動學公式與 6-6 佈局:平行機構的教科書標準內容(Stewart–Gough 平台)。
- 「基座與平台接頭多邊形不可相似」:Stewart–Gough 平台的已知奇異條件。
- 仰角範圍、長度比、接頭擺角、受力餘裕:經驗值與型錄典型值,僅供起步;沒有對特定產品查證。
