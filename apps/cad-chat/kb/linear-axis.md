# 直線軸:滾珠螺桿、線性滑軌、驅動馬達

## 適用情境

單軸或多軸直線運動(滑台、直線模組、龍門各軸、升降軸),需要你決定導程、螺桿徑、線軌規格、
馬達大小或支撐配置時。使用者已指定全部型號與尺寸時不必讀。皮帶/齒條/氣缸驅動的取捨看
`layout-selection.md`。

## 計算與選型

先把條件寫齊:移動質量 m(含載台、工件、上層軸)、行程 S、最高速度 v、加速時間 t(沒給就取
0.1–0.3 s)、水平或垂直、定位精度。缺的值是你的假設,標 assumed。

**1. 軸向力 F**
- 水平:F = μ·m·g + m·a。線軌滾動摩擦係數 μ 取 0.01(含密封阻力的保守值)。
- 垂直:F = m·g + m·a(上升加速段最大)。垂直軸斷電會掉,要有煞車或防墜。
- a = v / t。

**2. 導程與轉速**:v(mm/s)= 導程(mm)× 轉速(rpm)/ 60。
- 步進馬達的扭矩隨轉速下降,連續運轉以 **600 rpm 以下**規劃:導程 5 → 50 mm/s、導程 10 → 100 mm/s。
  要更快就加大導程,或明講需要伺服馬達(額定 3000 rpm)。
- 導程小 = 解析度高、推力大、速度低;導程大相反。

**3. 容許轉速**取下面兩者較小的:
- 螺桿危險轉速 n_c = f ×(d_r / L²)× 10⁷ rpm;d_r = 牙底徑(mm)、L = 支撐間距(mm);
  f 依支撐方式:固定–自由 3.4、支撐–支撐 9.7、**固定–支撐 15.1**、固定–固定 21.9。使用上限取 0.8·n_c。
- DN 值(珠心徑 mm × rpm):軋製級通用上限約 70,000,各型號以型錄為準。
- 細長比:支撐間距 / 螺桿徑超過約 60 要改大一級螺桿徑或加中間支撐。

**4. 馬達扭矩**
- 負載扭矩 T_L = F × 導程 /(2π × η),導程用公尺、η 取 0.9(滾珠螺桿 0.85–0.95)。
- 加速扭矩 T_a = J × α;負載折算慣量 J_L = m ×(導程/2π)²,螺桿慣量 J_s = π·ρ·d⁴·L/32
  (鋼 ρ = 7850 kg/m³),α = 2π·n/(60·t)。
- 所需扭矩 =(T_L + T_a)× 安全係數 1.5–2。
- 步進馬達型錄給的是**保持扭矩**,運轉中可用扭矩較低:沒有轉速–扭矩曲線時,以保持扭矩的一半當
  中速可用扭矩估算。負載慣量 / 轉子慣量建議 ≤ 10。

**5. 線軌**
- 一顆滑塊的等效負載 P:質量平均分給各滑塊,再加上偏心負載造成的力矩分量(重心偏出滑塊跨距外時
  單顆負載會遠大於平均)。
- 靜安全係數 f_S = C₀ / P:一般負載 1–3、有衝擊或振動 3–5。
- 額定壽命 L =(C /(f_w·P))³ × 50 km;負荷係數 f_w:平穩 1–1.2、一般 1.2–1.5、有衝擊 2 以上。
  要有實用壽命,C / P 至少 3–5。
- 配置:兩支軌、每軌兩顆滑塊;軌距取載台寬的 60–70% 以上;同軌兩滑塊的跨距不小於軌距的一半。
  驅動力作用線放在兩軌中間,偏離越遠越容易卡滯。

**6. 螺桿支撐與長度**
- 馬達側做固定端(成對角接觸軸承或深溝球軸承加鎖緊螺帽,承受軸向力),遠端做支撐端(單顆深溝球
  軸承,允許軸向浮動,吸收熱伸長)。短行程輕載可兩端都用深溝球軸承。
- 螺桿牙長 = 行程 + 螺帽長 + 兩端餘量(各 5–10 mm);總長再加兩端軸頸與聯軸器段。
- 馬達與螺桿之間用撓性聯軸器(梅花式或膜片式),不要剛性直連。

## 在本系統怎麼做

- 結構照參考模型 `models/linear_stage/linear_stage.py` 改編(尺寸鏈、定位常數表、運動宣告都齊)。
- 選型工具 `cad_source_part` 的輸入要你先算好:
  - `ball_screw={load_N, travel, target_speed_mm_s, accuracy?}`:load_N 傳第 1 步的 F。工具用
    「導程 × 額定轉速」反推導程,**預設額定轉速 3000 rpm(伺服)**;用步進馬達時在 requirement
    多帶 `"rated_rpm": 600`,否則會選到速度達不到的小導程。目錄:1605 / 1610 / 2005 / 2010(C7)。
  - `linear_guide={load_N, rail_len}`:工具直接拿 load_N 跟額定動負荷 C 比,**沒有內含安全係數**。
    傳入「單顆滑塊等效負載 P × 3–5」。目錄:MGN9C / MGN12C / MGN15C / HGH20CA。
  - `stepper={torque_Nm}`:工具比的是保持扭矩。傳入第 4 步的所需扭矩再 ×2(保持扭矩折半的反算)。
    目錄:NEMA11、NEMA17(三種長度)、NEMA23,最大保持扭矩 1.26 N·m——超過就回報需要更大馬達或
    加減速機,不要硬選。
  - `bearing={shaft_dia, radial_load_N?}`:shaft_dia 傳螺桿軸頸徑(約等於牙底徑再車小)。
- 幾何是簡化替身:螺桿是光桿、螺帽是圓筒,滑塊與軌、螺帽與桿之間留間隙不接觸。
- 運動宣告:一個 linear dof,moving 含載台、滑塊、螺帽與載台上的所有件;pairs 列滑塊×軌、螺帽×桿、
  載台×兩端軸承座。`_check_params` 至少擋:軌長 ≥ 行程 + 滑塊跨距 + 餘量;螺桿牙長 ≥ 行程 + 螺帽長。

## 做不到與要講明的事

- 本系統只驗幾何(干涉、行程內不相撞)。上面的推力、扭矩、壽命、危險轉速都是你算給使用者看的
  **估算**,不會被任何檢查驗證——回覆時列出用了哪些假設(質量、加速時間、效率、安全係數)。
- 不做剛性、撓度、熱伸長、背隙、定位精度的分析。使用者問到就說明這不在模型保證範圍。
- 目錄型號很少。算出來需要的規格超出目錄時照實回報,並說明用了哪個相近型號當外形替身。

## 來源與信心

- 危險轉速與 DN 值:THK 滾珠螺桿選型資料(容許轉速取危險轉速與 DN 值較小者、計算值乘 0.8);
  支撐係數為各廠通用值。DN 70,000 是通用經驗上限,型號專屬值以型錄為準。
- 線軌靜安全係數與 50 km 壽命式:HIWIN 線性滑軌技術資料。f_S 與 f_w 的範圍為型錄慣例值。
- 馬達扭矩=(負載扭矩+加速扭矩)× 安全係數、安全係數 1.5–2:Oriental Motor 選型計算資料。
  慣量比 ≤ 10 是保守經驗值(廠商容許值依機種可更高)。
- 摩擦係數 0.01、保持扭矩折半、軌距與跨距比例:經驗值。
