# 機構設計知識庫索引

設計模式的代理在需要「決定尺寸、選型或構型」時讀對應的檔(一次讀整檔)。
每行格式固定:`- 檔名|主題|何時讀`(系統提示會自動帶入這份清單;新增主題的做法見 README.md)。

- linear-axis.md|直線軸:滾珠螺桿、線性滑軌、驅動馬達|要定導程/螺桿徑/線軌規格/馬達扭矩,或估直線軸的推力、速度、行程與支撐配置
- pneumatic.md|氣壓:氣缸、夾爪、旋轉缸|要定缸徑/行程/安裝型式、夾爪夾持力、旋轉缸扭矩,或判斷要不要加導引
- rotary-drive.md|旋轉傳動:馬達、減速、齒輪、同步帶、聯軸器|要估旋轉負載的扭矩與慣量、選減速方式、定齒輪模數齒數中心距或帶輪齒數
- structure-fastening.md|機架與鎖付:螺絲孔、定位銷、配合、軸承座|要開螺絲孔/沉頭孔、定板厚與孔邊距、決定定位方式或軸孔配合
- layout-selection.md|自動化機構構型:直線驅動方式、取放機構、多軸堆疊|使用者只給功能(搬運/取放/翻轉/定位)沒指定機構,要提出構型方案與取捨
